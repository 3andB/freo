INSTALLATION STATUS

Inspect the installer. Test before relying on it.

Freo targets Ubuntu 24.04. The provisioning path exists, but it has not yet passed the separate fresh-VM acceptance test. It should not be treated as a verified one-command public install.

git clone https://github.com/lee-3andB/freo.git
cd freo
sudo ./scripts/install.sh

Review the script and installation documentation first. Administration currently uses the server CLI; browser controls for station changes are not available.

WHAT'S NEXT

More of the station, one honest step at a time.

Carts, live assist, audience features and authenticated browser controls for station changes remain future work. Freo does not yet offer hard-timed events, traffic scheduling or production-ready station operations.

No license has been selected yet. The owner must choose one before broadly promoting reuse as open-source software.
