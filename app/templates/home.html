Your station. Your server.

Good radio.
Solid foundations.

Freo connects a browser workspace to dedicated broadcast services. Your library, programming and confirmed history live in PostgreSQL; each managed station gets its own Liquidsoap process.

  1. CREATE & CONTROLFreo workspaceFlask + PostgreSQL
  2. SELECT & COORDINATEAutomation workerDurable programming & intent
  3. PLAY & MIXLiquidsoapOne engine per station
  4. DELIVER & LISTENIcecast + NginxYour public radio stream

Dedicated ingest and statistics workers support the station. Optional WebRTC microphone audio joins the engine through a separate gateway. The web app records validated commands; the automation worker controls the private playout connection.

PROJECT STATUS

Freo is an actively developing project for self-hosted internet radio. The production target is Ubuntu 24.04. A separate fresh-VM installation acceptance test remains outstanding; start with the requirements and current installation notes.

A few things to know.

What do I need to run Freo?

An Ubuntu 24.04 server, your music, and the services described in the setup guide. Plan for storage and stream bandwidth. Production browser access needs HTTPS. Station broadcast start/stop remains a server CLI operation.

Can I run more than one station?

Yes. Freo manages separate station engines and stream mounts. Share artists, albums or songs across channels without copying the audio. Station limits depend on installation configuration and any configured entitlements; current admin accounts manage all stations.

Can I broadcast from a microphone or mixer?

Yes, with the optional Live Mic gateway installed and configured. Use a browser microphone or an OS-recognized stereo USB mixer input. HTTPS and working WebRTC connectivity are required; some networks need TURN.

What does “self-hosted” mean here?

The application, database and audio services run on your server. Local statistics are collected separately from optional Central integration, which supports registration, aggregate reporting, directory metadata and cached entitlements. See the integration guide for details.

Where can I learn about the project and its license?

The source and documentation are available on GitHub. A software license has not yet been selected. Consult the repository for current project status and reuse terms.
